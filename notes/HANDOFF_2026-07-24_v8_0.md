## 1. One-paragraph state

The model question got its structural answer. v8.0 replaces
`p = logistic(K · composite_diff)` with
**`p = logistic(logit(market_novig) + λ · composite_diff)`, λ = 0** — the market
is the prior, the composite contributes only what λ earns, and K is deleted
rather than refitted (the clean resolution to the v7.1 locked-decision
amendment). λ = 0 is measured, not asserted: on the 70-row shadow archive the
offset-form fit is **λ = −0.76 ± 0.61**, CI [−1.96, +0.44], P(λ>0) = 9%, every
per-date and leave-one-date-out fit negative, and the market's Brier (0.2449)
beats the model's (0.2917). Both-sides EV shipped in the same version (H11 —
favorite-only selection was the other half of the damage path). Consequence, by
design: **the published probability IS the 9-book no-vig consensus, every edge
is ≤ 0, and the card is zero-pick every day until λ earns its way off zero.**
"Passing is a position," applied to the whole model. The system is now purely an
instrument: shadow accrues ~15 games/day toward the ~150-game λ decision in
early August.

## 8. Working practices that keep paying off

- Clone `--depth 1`, run against cached JSON; verify by execution, not reading.
- Regression-test against a real graded date; dedupe makes it repeatable —
  the only acceptable diff is the dedupe-counter lines.
- Changelog entry ships in the same commit as the code.
- After a browser upload: no `(1)` files, workflows in `.github/workflows/`,
  re-clone and diff.
- Check the frequency before hardening a guard; never test a rounded float for
  equality.
- Show Benjamin the measured interval BEFORE writing code that depends on it —
  the λ sequence is the template.
- **Check a suspicious coincidence rather than reporting it.** 07-24 and 07-25 composite
  sd both read 12.16 to 2dp, which looks like a stale snapshot; comparing the multisets
  showed different games and different values. Coincidence, confirmed, not assumed.
- **A number that looks *good* on a degenerate comparison is more dangerous than one that
  looks bad.** 4d's table reads as well-calibrated precisely because it compares the market
  to itself.
- Claude's memory is a summary and drifts — the repo, this file, and the
  execution queue are the source of truth. **Revised 07-26 against a live clone; where
